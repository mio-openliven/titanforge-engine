# Terms

## TitanForge Engine

The external procedural toolkit for generating cinematic Minecraft maps.

Version priorities:

- Primary product target: Minecraft 1.21.11
- Secondary compatibility target: Minecraft 1.12.2

## Mask

An image or grid-like input that marks regions, weights, roads, biomes, height influences, placement zones, or exclusions.

## Layout

The high-level composition of a map: regions, routes, landmarks, camera/cinematic beats, and placement intent.

## Terrain Pass

A generation step that modifies terrain data, for example height, materials, smoothing, erosion-like shaping, or biome assignment.

## Schematic

A structure asset that can be placed into the generated world or exported for Minecraft tooling.

## Preview

A fast visual or textual diagnostic output used to inspect generation before opening the result in Minecraft.

## Exporter

A module that writes generated data to a target format such as schematic, NBT, images, JSON, or Minecraft world files.
