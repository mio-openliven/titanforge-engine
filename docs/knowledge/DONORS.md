# Donor Research

Donors are reference projects, libraries, formats, or tools that can teach the project. They are not code to blindly copy.

## Selection Rule

Start with 10 to 15 donors. Each donor should answer at least one important question:

- How to read or write modern Minecraft data for the primary 1.21.11 target?
- How to provide a compatibility path for Minecraft 1.12.2 without making it the core design?
- How to handle schematics and NBT safely?
- How to generate terrain from masks or heightmaps?
- How to preview maps quickly?
- How to structure a procedural pipeline?
- How to manage large assets without destroying Git history?

## Donor Card Template

Name:

## Candidate Donor Types

- WorldEdit schematic format references
- Sponge schematic format references
- NBT parsing libraries
- Minecraft Anvil region tooling
- Heightmap and mask-processing projects
- Procedural terrain generation examples
- Tile or region preview renderers
- Asset pipeline examples
- Existing map-generation tools
- Git LFS and large-repo workflows
