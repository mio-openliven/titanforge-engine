# Simple Next Steps

## What To Do

1. If confused, open Window 0 Control / Ideas.
2. Paste the Window 0 prompt from `docs/operations/CHAT_ROLES.md`.
3. It tells you which window to use next.
4. For coding, open Window 2 Builder and tell it: `Do TF-002`.
5. When done, open Window 4 Reviewer and ask it to review the last commit.

## What TitanForge Can Do Now

It can make a folder that shows a Minecraft location plan:

- original mask
- preview
- cleaned preview
- JSON layout
- heightmap preview
- report
- manifest

It does not create a Minecraft world yet.

## Do Not Do Yet

- Do not ask for GUI.
- Do not ask for AI magic.
- Do not ask for huge city export.
- Do not import random donor code.

Ask for one task at a time.
