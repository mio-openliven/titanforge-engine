# One-Week Plan

## Goal

Make TitanForge feel like a real tool, not a chat experiment.

## Day 1

Stabilize project rules:

- `AGENTS.md`
- `tasks.md`
- PRD
- role prompts
- skills

## Day 2

Improve location pack review:

- terrain color preview
- simpler report
- clearer manifest

## Day 3

Improve terrain preview:

- coastline cleanup/smoothing preview
- water depth preview idea
- better demo presets

## Day 4

Add first neutral terrain grid:

- cells
- zones
- heights
- material intent

## Day 5

Create first export experiment:

- choose `.schematic` or internal block preview
- do the smallest possible output

## Day 6

Polish user workflow:

- example masks
- command docs
- smoke scripts
- bug fixes

## Day 7

Demo and review:

- run from clean checkout
- record what works
- list next 10 tasks
- decide if Minecraft export is next

## Rule

Every day must end with a visible artifact and green tests.
